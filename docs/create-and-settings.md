# パック作成・設定・言語

## 設定

「設定」で表示言語を日本語／英語から選べます。PackerMODの表示はすぐに切り替わり、次回起動にも保存されます。Luanti本体の表示言語は再起動後に反映されます。

全体設定は「一般・操作・キーマップ・映像・音声・表示」に分けます。キー割り当ては独立した「キーマップ」へ集約し、移動・アクション・ホットバー・チャット・視点／HUD・システムの小タブで整理します。「操作」にはマウスやタッチ、移動の動作だけを置きます。

通常は基本項目だけを表示します。「上級者」を押すと通信や技術的なパラメータ、「開発用」を押すとデバッグ・プロファイラなどを表示します。両者は独立して切り替えられ、初期状態はオフです。検索にも同じ条件を適用し、非表示の複雑な項目を検索から開くことはできません。

項目はページ切替ではなくスクロールで表示します。各行の「戻す」でその項目だけを既定値へ戻し、キー割り当ても同じ場所から初期化できます。プレイ済みワールドの地形など、変更できない項目は初期化もできません。行の「...」から説明と専用編集を開き、戻ってもスクロール位置を保持します。

「一般」または「表示 → サイズ・表示」の「GUIの大きさ」1項目で、文字・ボタン・余白を同じ比率で拡縮します。選択肢は「自動・小・標準・大」で、現在のウィンドウに収まるサイズだけを表示します。「戻す」は自動へ戻します。変更・初期化はすぐに保存されます。サイズに応じてナビゲーションやパック一覧の列数も調整します。

本体の設定定義から型・既定値・範囲・選択肢を読み込み、項目と説明には本体の翻訳を利用します。一部の設定は再起動後や新しいワールドの作成時に反映されます。

## ワールドごとの設定

パックを開き、ワールドを選択して「ワールド編集」を押します。「ゲームルール・物理／移動・地形生成・サーバー」の設定は選択したワールドだけに保存し、全体設定や別ワールドの検索には表示しません。

ルール・物理・サーバー設定はそのワールドの `world.mt`、地形生成の編集値は `packermod-mapgen.conf` に保存します。新しいワールドは「作成して設定」からプレイ前に設定できます。地形生成値は初回起動前に `map_meta.txt` へ反映し、プレイ済みワールドでは確認のみとします。既存の地形・プレイヤー・MOD構成を上書きしません。

Luanti本体へ渡すサーバー設定は起動時だけ適用し、メニューへ戻ったときに元の全体設定を復元します。異常終了でも次回起動時に復元できるよう、適用前の値を `PackerMOD/world-session.json` に記録します。

メニューのサンドボックスはシェル実行を許可しないため、起動時はワールドディレクトリを同じユーザーデータ内へ一時配置し、終了時に元のパックへ戻します。移動前に `PackerMOD/launch-world.json` を保存し、異常終了後も先に復旧します。両方の保存先にデータがある場合は上書きせず停止し、不明な起動ディレクトリのデータを再帰削除しません。

## パックを作成

1. 「パックを作成」で名前と説明を入力します。作成者は任意です。
2. 「ゲーム選択」でContentDBを検索し、結果からベースゲームを選択します。プルダウンには、このLuantiに対応する公開版だけが表示されます。インストール済みのゲームも選べます。
3. 必要なMODを検索・追加します。追加するMODの対応版は自動で選びます。
4. 「パックを作成」で、選んだゲームの公開版を取得・配置してからパックを保存します。

ゲーム検索・公開版取得・ダウンロード中も画面を操作できます。取得に失敗した場合はエラーを表示し、パックを保存しません。違う公開版は別のゲームフォルダに配置し、既存の公開版を上書きしません。

Pack IDはUUIDで自動生成します。パックの版は1.0.0から始まり、MODや情報の編集保存で末尾の番号が自動で増えます。ゲームの公開版とは別で、どちらもPack作成時にIDや数値を手入力する必要はありません。

## レイアウト

画面比率から使える高さを計算します。ラベルと入力欄を分けて積み上げ、行の高さは内容から求めます。ボタンは表示する文字列に応じた幅を取り、列はflexの比率で残りの幅を分けます。ダイアログは内容に合わせて伸び、画面内の最大高で制限します。

余白・文字・コントロールの基本寸法は共通の尺度として持ち、画面ごとの座標調整を避けています。

## 検証

- Luaテストと分離したLuanti実起動テスト。
- 日本語／英語、3段階の作成、同じGUIに統合した本体設定の型別スクリーンショット。
- 実際の本体Settings APIによる保存・初期化・不正値拒否。一時ユーザーデータのみを使用。
- ContentDBの実検索結果からの選択と公開版プルダウン。
- 実ゲームのダウンロード・展開・Pack保存。一時ユーザーデータのみを使用。

実行コマンドは [visual-tests.md](visual-tests.md) を参照してください。


## 表示サイズの安全制限

「自動」は現在のウィンドウに収まる最大サイズを選びます。ウィンドウのリサイズ時も再計算し、手動で選んだサイズが収まらなくなった場合は収まる段階へ切り替えます。旧バージョンの文字・ボタン個別倍率は共通比率へ移行し、本体のGUI倍率やフォントサイズを別々に変更する項目は一覧・検索に出しません。

言語は一覧のプルダウンから選択します。スライダーの高さとつまみの割合を確保し、下部の説明はスクロールバーの出ないラベルで表示します。「上級者」「開発用」の表示状態は別々に設定ファイルへ保存し、画面の再表示・再起動後も引き継ぎます。
