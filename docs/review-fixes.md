# PackerMOD レビュー修正一覧

## データと動作

- [x] 同じIDのZIP取り込みで既存Packを削除していた処理を撤去。ZIP／YAML／Create共通で重複IDを拒否し、ワールドを上書きしない。
- [x] manifest書き込み失敗を成功扱いしない。MOD編集の保存に失敗した場合はメモリ上の変更も戻す。
- [x] 既存ワールドのMOD構成を、次回起動前にPackのmanifestへ同期する。新規ワールドでは初期構成を記録する。
- [x] MOD更新は別ディレクトリで準備し、ダウンロードや配置に失敗した場合は元の構成を維持。切り替え途中でのエラーも元へ戻す。
- [x] 更新前の `worldmods`、`world.mt`、構成記録はワールド内の `.packermod-backup-*` に保存。マップ・プレイヤーDBは変更しない。Pack管理外のMODは保持する。
- [x] 構成記録を安定したキー順で保存し、同じ構成を再起動のたびに再インストールしない。
- [x] ワールド起動用リンクを表示名ではなくディレクトリ名で照合する。
- [x] MOD名のパス文字を拒否し、更新対象が `worldmods` の外へ出ないようにする。
- [x] Pack IDのハイフン／アンダースコアによるボタン名の衝突を防ぐ。
- [x] ディレクトリの存在確認と作成失敗の検出を修正する。

- `make all`: Luaテスト262件成功、Luanti実起動のE2Eテスト成功。
- 1280×800で12画面、1024×768で一覧と作成画面を撮影し目視確認。
- データ損失を避けるため、重複Packを更新として取り込む機能は設けず、明示的なエラーにした。

## 設定・作成手順・日本語対応の追加修正

- [x] 未実装だった設定ボタンをLuanti標準設定ダイアログへ接続。
- [x] 表示言語は日本語が既定。PackerMODの設定で日本語／英語を切替・保存できる。本体の言語も保存し、再起動後に反映。
- [x] 作成手順は「パック情報 → ベースゲーム → MOD」。Pack IDと版の入力欄を撤去。
- [x] Pack IDはUUID v4形式で自動生成。初版は1.0.0、編集保存ごとに版を自動更新。
- [x] ベースゲームはContentDBで検索し、Luantiの対応版だけをプルダウンで選択。インストール済みのゲームも選べる。

- [x] HTTP APIを実際のLuantiの呼び出し規約へ修正。
- [x] ラベルと入力欄を別要素として積み、内側の余白を確保。行の高さとボタン幅を内容から計算し、列幅はflex比率で配分。
- [x] ダイアログは内容に合わせた高さと画面内の最大高を使い、画面比率から利用可能な高さを決定する。
- [x] 自動撮影に日本語／英語、Luanti標準設定、ContentDB実通信の検証を追加。

ContentDB実通信では、検索結果の選択と版プルダウンの描画、Minetest Gameの取得・展開・Pack保存までを一時環境で確認した。
