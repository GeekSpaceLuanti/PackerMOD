# 独立ゲーム化の作業リスト

方針決定日: 2026-11-05。Minetest Gameを土台に、Java版らしい基本操作と
Luanti用MODで拡張できる基盤を育てる。コンテンツ追加は後に回す。

チェックは実装・検証の証拠が揃った項目だけに付ける。

## 今回の基盤整備

- [x] PackerMOD独自コードのライセンスを明示し、LGPL/GPL本文を配置する。
- [x] PixelarticonsのMIT全文、生成素材の扱い、ゲーム個別通知の保持方針を記録する。
- [x] 旧VoxeLibre案をMinetest Gameベースの3層構成へ更新する。
- [x] Minetest Gameの特定コミットを固定して `games/packerbase` に取り込む。
- [x] 上流コード・素材の著作権・ライセンス通知を保持する。
- [x] `packer_core` にバージョン付きの最小拡張APIを用意する。
- [x] 保存形式の版を記録し、未知の将来版を安全に拒否する。
- [x] 任意の性能計測機構を用意し、通常時の余分な計測負荷を抑える。
- [x] Windows/Linuxの導入でゲームと通知を配置する。
- [x] インストール済みゲームからPack作成・ゲーム起動を確認する。
- [x] 一時ワールドで保存・再起動と追加MODのAPI利用を確認する。
- [x] Luaテスト、既存E2E、WSL＋Xvfb画面確認を行う。
- [x] 実Windows版へ反映し、バックアップ・配置ハッシュ・保護データを検証する。
- [x] Windows版を起動し、メニューとゲーム起動を確認する。
- [x] ホットバー9枠・個人インベントリ36枠を実装して実クライアントで検証する。
- [x] 新規ワールドのMOD保存先をSQLite3に統一する（既存ワールドは自動移行しない）。
- [x] API利用サンプルと、ソース・starter ZIPの生成スクリプトを用意する。

## 次の開発: Java版の基本体験

- [ ] 対象とするJava版の操作仕様を固定し、比較用シーンと測定条件を作る。
- [ ] 移動速度、加減速、ジャンプ、スプリント、スニークを個別に比較する。
- [ ] 採掘時間、設置の連続入力、射程、アイテム拾得を比較する。
- [ ] ホットバーとインベントリのクリック・分割・移動操作を比較する。
- [ ] カメラ、入力、画面UIでLua APIに足りない機能を列挙する。
- [ ] エンジン改修が必要な項目だけ小さいパッチとして実装し、専用クライアントを検証する。

「Java版と同等」という判定は、上記の比較を行うまで付けない。

## 次の開発: MOD拡張性

- [ ] ゲーム基盤と交換可能な機能MODの責務を分ける。
- [ ] 移動・戦闘・クラフト・インベントリ等のイベントと拡張点を仕様化する。
- [ ] レシピ・アイテム分類・設定等の共通データ定義を整理する。
- [ ] 外部MODの例を別パッケージで作り、基盤を書き換えず拡張できるか確認する。
- [ ] 公開API文書、サンプル、非推奨の告知方法を整備する。

## 次の開発: 互換性

- [ ] 対応Luanti版、ゲームAPI版、Pack形式、保存形式を独立して管理する。
- [ ] Packごとのゲーム版固定と複数版併存を、実際のインストール経路まで実装する。
- [ ] 代表的なMinetest Game用MODを選び、互換性表を作る。
- [ ] 保存データ移行をバックアップ付きで検証し、既存ワールドの自動上書きを避ける。
- [ ] 配布物とソースの版・ハッシュを固定し、再現可能なリリース手順を作る。

## 次の開発: 性能

- [ ] 同じシード・視点・描画距離・MOD構成で再現できるベンチマークを作る。
- [ ] FPSだけでなくフレーム時間、サーバー処理時間、地形生成、保存時間を測る。
- [ ] Luanti profilerでMOD別の重い処理を特定し、イベント駆動・実行頻度を改善する。
- [ ] 描画・通信・地形生成のエンジン変更は、それぞれ改善前後の数値で判断する。
- [ ] MOD数やプレイヤー数を増やした負荷試験で、性能退行を検出する。

## 今回の検証結果

347件の既存Luaテスト、Base専用API・headless保存再起動、Windows/Linux隔離導入、
WSL＋Xvfb画像のサブエージェントレビュー、実Windows版のPack作成・追加MOD・
日本語ワールド・2回起動が成功。詳細と制約は [基盤統合の検証記録](base-integration-report.md)。
Java版との挙動一致や性能向上は未計測であり、上記の継続項目は未完了。
