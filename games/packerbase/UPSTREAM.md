# PackerMOD Base 0.1.0

Forked from https://github.com/luanti-org/minetest_game

Upstream commit: `9e895af6e9feb98332fa1a778001442f5669bc20`

Retrieved: 2026-11-05. Upstream copyright, license notices, mod names,
assets and APIs are retained. Changes: game title/description/version,
walking-speed default, two settings in settingtypes.txt, and the new
`packer_core` mod (including nine-slot hotbar/36-slot player inventory). See `LICENSE.txt`
and each upstream mod's license/readme for the original terms.

The directory/game ID is `packerbase`. Its release version is independent
of the upstream revision. No upstream content was removed or renamed.
Future releases must migrate saves explicitly rather than silently
reinterpreting old node names or data. Existing Minetest Game worlds are
not automatically converted.

The `README.md` and `game_api.txt` describe upstream Minetest Game.
PackerMOD-specific API and remaining work are in `PACKERBASE.md`.
